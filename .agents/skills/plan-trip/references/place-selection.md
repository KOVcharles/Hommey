# 地点选择与城市约束

大范围目的地是约束。例如目的地重庆，不能提供南京的同名会场。

1. 已知城市后，在该城市搜索公司、会场或完整地址；没有城市先收集城市。用户从候选中选择，界面显示名称、城市、区县和详细地址。
2. 搜索参数设置城市限制，服务端仍核对返回地点的城市。无同城结果就说明无结果，不用其他城市凑选项。
3. 提交时服务端按 POI ID 向高德复核，并检查城市与本次目的地一致；客户端名称、坐标不是事实来源。
4. 改城市或编辑地点文字后，旧选择立即失效。取消旧搜索并丢弃晚到的结果，不能让旧城市的选项重新出现。
5. 已验证地点包含稳定 POI ID、名称、城市、行政代码和坐标。酒店查询使用这个坐标；不能再用名称模糊搜索并静默选另一个地点。
6. 首次确认行程的卡片直接包含地点选择器；不要先给一张冗长的制度/记忆卡片再询问会场。结果卡片显示会场与酒店标记，点击酒店联动地图。
7. 编辑会场仅为待提交选择；旧卡片继续代表旧结果。确认修改后经过同一提交链路，重新查询并追加新卡片。查询失败明确显示，不能沿用旧酒店作为新地点的结果。

用户自然语言提供地点名称时可用作搜索词，但没有确认 POI 前不称为精确位置。接口不可用时保留已知城市、车次和用户文字，提示稍后重试；不要要求用户代替地图提供经纬度。
