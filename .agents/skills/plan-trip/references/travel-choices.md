# 车次、酒店与结果交付

## 车次

城市输入通过 12306 站名表映射到实际车站；用户明确指定车站时保持该站。展示日期、出发/到达站、时刻、历时和席别余票，保留查询时间。

候选优先有票，其次历时，允许按席别筛选。会议时间未明确时只展示候选，不声称某趟车保证赶上会议。确认会议时间后，还要考虑站内出站和到会场通勤缓冲。

当前接口没有提供票价，明确标注并提供 12306 核实入口。空结果、查询失败和用户排除是不同状态；失败不得伪造示例车次填充产品界面。

## 附近酒店

基于用户确认的工作地点坐标查询周边候选，先在候选集中匹配已有品牌偏好，再比较距离与评分。没有匹配品牌时说明按距离提供其他选择，不说满足了偏好。展示酒店名、地址、距离、可用评分、推荐原因和地图入口。

高德距离不等于通勤时间。参考消费不等于指定入住日房价或可订房态，不能据此断言符合住宿限额。没有价格不阻止展示酒店位置。

## 最终交付

首屏显示本次路线、日期和关键未完成项；随后是车次、准确地点、附近酒店。制度证据按需展开，个人偏好用于排序而不是全文复述。用户需要做的下一步必须有相应输入或操作。

任何一项外部查询失败，都保留其他成功结果与已确认地点。重新查询沿用当前行程和排除项；取消或修改行程后不继续使用旧版本结果。
