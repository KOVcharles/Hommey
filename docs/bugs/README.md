# Bug 记录

本目录集中保存已经复现并完成根因分析的产品与工程 Bug，避免与版本 Changelog、
实施计划和设计文档混放。

## 文件命名

```text
YYYY-MM-DD-简短英文主题.md
```

每份记录至少包含：用户现象、实际执行证据、根因、修复范围、验收结果，以及尚未
消除的风险。技术状态“已修复”和“部分修复”必须区分；未完成的结构性问题不能因
特定复现路径已被阻断而标记为完全关闭。
