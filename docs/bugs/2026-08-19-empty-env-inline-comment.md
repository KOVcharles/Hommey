# 空环境变量的行尾注释被解析为配置值 Bug 记录

> 编号：BUG-2026-08-19-01<br>
> 发现日期：2026-08-19<br>
> 状态：已修复

## 1. 用户现象

应用或测试初始化 PostgreSQL 连接池时持续重试，约 10 秒后抛出
`psycopg_pool.PoolTimeout`，底层错误为连接串中 `#` 后缺少 `=`。

## 2. 实际执行证据

`.env` 曾使用以下形式表示空配置：

```dotenv
HOMMEY_RAG_POSTGRES_DSN=  # 留空时复用主 DSN
```

当前 `python-dotenv` 会把 `# 留空时复用主 DSN` 解析成非空字符串。该字符串进入
PostgreSQL 连接池后被当成 DSN，产生 `missing "=" after "#"`，最终连接池超时。

## 3. 根因

项目把“空值”和“说明注释”写在同一行，并假设 dotenv 会忽略行尾注释；实际解析
规则没有满足这个假设。受影响的不只 PostgreSQL DSN，还包括 Judge 模型连接、聚合
车次 Key 和 OCR Key 等本应保持空值并触发回退逻辑的配置。

## 4. 修复范围

- 将所有“空值 + 行尾注释”改为上一行独立注释，变量行只保留 `KEY=`。
- 同步修正 `.env.example`，避免服务器部署时再次复制错误写法。
- PostgreSQL DSN 留空后可正常进入既定的复用或未配置分支，不再把说明文字交给驱动。

## 5. 验收结果

- 扫描 `.env` 与 `.env.example`，不存在空值后紧跟行尾注释的配置项。
- 相关定向回归：`67 passed`。
- 完整回归：`595 passed, 27 skipped`。
- Compose 配置解析通过。

## 6. 剩余风险

外部服务器若维护了独立 `.env`，仍需同步采用“注释独占一行”的写法。后续新增可空
配置时也应遵循该格式，尤其是 DSN、API Key、模型名和 Base URL。
