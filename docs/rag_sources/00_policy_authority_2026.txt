差旅政策治理与核心规则索引（2026版）

文档编号：TRAVEL-GOV-2026-01
版本：2.0
生效日期：2026年1月1日
适用范围：公司员工因公发生的国内和国际差旅测试场景
制度归口：人力资源部与财务部

一、文档目的

本文件是差旅知识库的最高层级内部核心规则索引，用于统一术语、规则优先级、金额口径和审批边界。知识库中的政策、指南、FAQ、城市提示和测试案例必须按本文件解释。

本知识库为功能测试数据，不代表任何真实企业的现行制度。回答必须以检索到的明确证据为基础；证据不足时应返回“未知/需人工确认”，不得补造金额、审批人或时限。

二、规则优先级

1. 法律法规、政府要求和人身安全要求优先。
2. 针对具体行程且仍在有效期内的书面例外审批，优先于一般费用标准。
3. 本核心规则索引优先于其他内部知识库文件。
4. 国内差旅、国际差旅、费用报销和例外审批专项制度，仅在各自主题内适用。
5. 操作指南和FAQ只解释制度，不单独创设报销权利。
6. 城市信息和环保倡议属于建议，不得改变费用上限或审批权限。
7. 同层级文件冲突时，以生效日期较晚者为准；同日仍冲突时必须人工确认。

【禁止规则】不得把“建议”“鼓励”“平台提示”解释为强制报销资格，也不得把“可以申请”解释为“自动批准”。

三、统一判定流程

每个合规问题按以下顺序判断：先确认国内或国际；再确认费用类别和城市/地区；然后计算基础标准；再检查是否存在安全情形或有效例外审批；最后核对票据、时限和个人消费排除项。

如果缺少目的地、日期、费用类别、实际金额、审批状态或票据状态等关键字段，应指出缺失信息。不能因为相似案例曾获批准，就推定当前行程也已获批准。

四、国内交通核心规则

1. 高铁和动车原则上限二等座及以下。22:00至次日06:00的夜间行程可以选择普通卧铺。商务座只代表“可申请”，必须有书面例外审批。
2. 国内航班限经济舱。付费选座、机场贵宾厅和个人原因升舱不予报销，除非例外审批矩阵明确允许。
3. 机场或火车站接送、业务拜访、携带重要物品、公共交通不可达或夜间安全场景可以合理打车。普通市内办公优先公共交通或公司班车。
4. 租车适用于多地出差、偏远地区或携带大量工作物品，须提前在申请中说明，标准车型为经济型轿车。
5. 短途高铁和绿色出行属于优先建议；在安全、无障碍或业务时效不适合时，不强制采用。

五、国内住宿核心规则

1. 一线城市：北京、上海、广州、深圳，基础上限500元/间夜。
2. 二线城市：杭州、南京、成都、武汉、西安及其他省会城市，基础上限400元/间夜。
3. 三线及以下城市及县域，基础上限300元/间夜。
4. 西藏、新疆、青海的城市，先按城市层级确定基础上限，再允许上浮20%。例如拉萨按省会城市400元计算，上浮后上限为480元/间夜。
5. 住宿上限按每间夜含税总价计算，包括房费、强制服务费、税费和酒店打包早餐；押金和个人消费不计入可报销房费。
6. 大型展会、极端天气或临时安全安置等其他上浮，不与特殊地区20%上浮叠加；适用多个上浮条件时，只取已获批准的最高一个比例。

六、国内餐饮核心规则

1. 国内差旅不发放额外按天补贴，采用凭票实报实销。
2. 酒店不含早餐时，早餐每餐上限30元；酒店已含早餐时不得重复报销早餐。
3. 午餐和晚餐每餐上限100元。无例外审批时，超过上限只报销至上限。
4. 普通零食、酒水和个人娱乐不予报销。业务招待不适用普通工作餐规则，但必须提供业务说明、参与人员和明细；单次超过500元须主管审批。

七、审批核心规则

1. 一般国内出差由直属主管审批。
2. 国际出差由部门总监审批。
3. 连续出差超过10天、住宿超标超过30%、高风险地区和其他重大例外由部门总监审批。
4. 住宿或其他标准超出基础上限不超过30%（含30%），由直属主管提前审批；超过30%由部门总监提前审批。
5. “提前审批”是指出行或消费发生前获得可追溯的系统或书面批准。口头同意不等于有效审批。
6. 只有突发安全事件、供应商中断或无法预见的紧急公务允许事后补审批。员工应尽快通知主管，并在返程后3个自然日内补齐。

八、报销核心规则

1. 常规费用应在出差结束后30个自然日内提交。
2. 11月30日及以前发生的费用，应在当年12月31日前完成报销。
3. 12月1日至12月31日发生的费用，可在次年1月15日前提交。
4. 真实、合法、与公务相符且未重复报销的票据是基本要求。票据遗失只能申请例外审核，不代表必然获批。
5. 未经审批的超标部分、个人旅游、家属费用、罚款、酒店minibar、SPA、付费电影和个人购物不予报销。
6. 因公务携带设备或样品产生的必要超重行李费可以报销；个人行李超重不予报销。
7. 机场停车费原则上不予报销；业务拜访发生的合理停车费可凭票报销。

九、国际差旅引用规则

国际住宿、餐费、航班舱位、汇率和境外票据按《国际差旅管理办法（2026版）》执行。国内餐饮“早餐30元、午晚餐各100元”的标准不得套用到国际差旅。

十、回答与引用要求

回答应给出结论、适用标准、审批条件和缺失信息，并尽可能标注文档编号。对于法律、铁路实时规则、航班退改签、签证、天气和城市交通等可能变化的信息，应提示查询权威实时来源。
