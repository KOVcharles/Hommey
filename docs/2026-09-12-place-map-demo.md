# 地点与地图联动 Demo

入口：<http://localhost:8000/static/design-demos/place-map.html>

这是独立交互 Demo，未改动正式聊天的提交流程，也不保存行程。

## 已实现

- 重庆、南京各三个真实高德 POI，以及各会场附近三个酒店的公开数据快照。
- 点击地点切换真实地图底图和定位针；地图标记与候选列表联动。
- 明确确认地点后展示附近酒店，编号对应，点击酒店高亮地图位置并显示地址、距离、评分和高德链接。
- 编辑搜索使待确认选择失效；切换城市清除旧地点与酒店。搜索只匹配当前城市的预置样本，不假装提供无限实时搜索。
- 支持滚轮与加减按钮在 13—15 级之间连续缩放，预加载三个底图层级，通过逐帧插值和清晰度层淡入切换；支持回到会场、展开/收起地图及手机布局。
- 定位针使用 22×28px 的简洁 SVG，酒店使用小号数字标记；标记大小固定，地理位置随缩放逐帧更新。
- 底图保留高德原有署名和审图信息，API Key 不进入前端或快照文件。

## 技术范围

现有配置仅包含高德 Web 服务 Key。本版调用静态地图 API 生成真实底图，前端叠加可交互标记。图片与地点数据均在制作 Demo 时获取，不包含员工个人信息。

没有实现自由拖动、任意地点实时地图或本人实时定位。正式接入完整地图应配置 Web 端 JS API Key 与安全码，使用 SDK 管理地图视角与标记；继续复用服务端城市范围校验。

静态底图的 scale=1 像素比例已通过高德原生 Marker 校准：以重庆会场附近的第三个酒店为对照，13 级底图标记位置约为 (206,106)，避免按常规 256 像素瓦片投影产生偏移。

## 验证与复现

生成快照：`docker exec -e PYTHONPATH=/app hommey-app python scripts/build_place_map_demo.py`

浏览器检查：`.venv/Scripts/python.exe tests/check_place_map_demo.py`

已验证：真实底图加载、地点切换、酒店与定位针联动、加减按钮的连续中间帧、滚轮不带动页面滚动、快速反向缩放收敛、定位针尺寸不变、动画中切换城市、展开与 Escape 收起、跨城市清空、无匹配结果、编辑失效和 Enter 选择。桌面与 390px 手机截图检查通过，无横向溢出。系统启用减少动态效果时直接完成缩放。

快照生成器缓存已有图片；数据更新后如需刷新底图，应在明确的 Demo 资源目录中选择性更新对应图片。切勿将图片缩放比例直接套用于未来 JS SDK，SDK 应直接接受高德经纬度。
