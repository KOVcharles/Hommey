# 报销对话与可合并知识库实施记录

日期：2026-09-20。首期实现：现有聊天中的报销制度咨询与知识目录分区。

2026-10-04 清理更新：原企业演示资料、生成脚本和 `docs` 内重复 PDF 已移除，现仅维护 `data/documents/cqu/finance` 中的原文；README 维护说明不参与入库。当前目录说明见 `data/documents/README.md`。

## 产品范围

用户可以直接询问日常报销、版面费、会议费、专家酬金和差旅要求，再在同一对话补充或修订经费来源等条件。复用 policy_rag、findings、evidence_refs 和原有来源展示，不新增 Agent、报销表单、审批流或持久化的报销上下文。原有差旅功能继续使用。

新用户进入首页即可提问，移除了前端强制差旅偏好问卷。偏好仍可在自然对话中表达。咨询条件留在会话中，不写入行程和长期偏好；仅在影响答案时补问。

## 唯一的文档身份与检索范围

实现采用既有 `document_id` 的目录前缀，不增加原设计中拟议的 `knowledge_scope` 字段，也不新增数据库列。规范身份根目录始终为 `data/documents`；按子目录或全库导入均得到 `cqu/finance/文件名.pdf`。

当前生效文件是 `data/documents/cqu/finance/重庆大学财务报销指南-2025年版.pdf`。原企业演示资料已清理。

上述 data/documents 文件是唯一维护的 PDF。后续维护更新这一个入库文件，不能按问答主题复制多份。文档内容及其既有版本、页码和标题路径是制度依据，不建立平行的金额或材料规则表。

当前部署配置为 `HOMMEY_RAG_SEARCH_SCOPES=cqu/finance`。配置在创建检索器时读取，更改后重启应用。向量召回和 BM25 数据集在候选选择前按相同目录前缀过滤。查不到时不会扩大范围。空配置保留原来的全库检索行为，不适合用作高校制度隔离配置。

现有 BM25 每次从受限文档集建立索引，没有额外的跨范围答案缓存。Embedding 缓存只缓存文本向量，不承载政策结论。历史会话的政策结果在采纳前沿用原有有效性检查，拒绝当前目录范围之外的来源。

范围是部署配置，不是用户授权系统。以后若需不同用户访问不同资料，再接入权限模型；本次不增加多租户逻辑。同一范围内已保存的历史答案也不会自动被新版指南重写，需要重新提问检索。

## 上传、查阅与后续合并

知识库页面仍列出全部资料，并明确展示当前回答范围。新上传文件自动进入第一个配置目录；不增加目录必填字段。原有路径校验、同名拒绝、预览、删除和刷新任务继续复用。

后续可直接加入 cqu/research 等目录。新文件按原刷新流程导入后，配置为 `HOMMEY_RAG_SEARCH_SCOPES=cqu/finance,cqu/research`。

已入库资料扩大检索范围不需要重新生成文档 ID 或修改聊天协议。若将来迁移到更大的 RAG collection，保持规范文档 ID 和来源信息，迁移后核对去重、引用和检索质量，再切换配置即可。当前没有实现跨多个物理 collection 的排名融合。

## PDF 解析修复

真实入库发现跨页章节会丢失“使用科研经费报销”的适用条件，因此 PDF 解析改为在同一文档各页间延续既有标题栈。保留原文条目编号，并将合并多个同级条款的切片标题限定为共同上级，避免把第一条的标题错误套给整块内容。

解析器与切片器版本已更新，并通过既有后台刷新队列重建索引。物理页 11 的科研经费住宿标准、物理页 12 的其他经费标准，以及版面费限制均有实际 PDF 回归验证。

## 验证与边界

- 173 项相关回归通过，涵盖真实 PDF、PostgreSQL 向量/BM25/混合检索、空范围结果、多个目录、规范文档 ID、上传、历史来源、原有对话和状态流程；随后针对提示词和展示调整重跑 84 项，执行计划文案另通过 22 项。
- 实际检索验证版面费与电子发票问题只返回 cqu/finance 来源。
- 浏览器实测：新用户直接提问、版面费材料咨询、补充国家社科基金条件、电子发票原 PDF 要求、知识库分区提示；咨询期间行程与偏好相关表均未新增记录。页面无 JavaScript 错误。
- 实测暴露过相邻条款被扩大解释的问题，已在提示中强调章节与业务适用范围。该约束仍由模型执行，不能将此次有限场景验证等同于全部政策问答准确率保证。
- 本期提供制度咨询和材料准备建议，不执行付款、审批或报销提交；未增加票据自动审核、报销台账或跨库物理融合服务。
- 来源固定为提供的 2025 版指南；新制度需维护知识文件并刷新。模型答案仍需结合来源和具体适用条件核对。
