# 制度知识库

本目录是 RAG 文档身份的根目录，支持 `.txt`、`.md` 和可提取文本的 `.pdf`，递归导入子目录。

当前报销知识在 `cqu/finance/重庆大学财务报销指南-2025年版.pdf`。`docs` 中的原始文件用于归档，不参与索引；后续更新入库版本时维护此目录中的文件并执行知识库刷新，不按问题类型复制制度。

`HOMMEY_RAG_SEARCH_SCOPES=cqu/finance` 使当前回答仅使用该分区，原企业演示资料仍可查阅，但不参与当前回答。目录归属直接使用既有 `document_id`，不另存重复的 scope 字段。上传文件进入配置中的第一个分区。

后续可加入 `cqu/research` 等目录，刷新新资料，并将配置改成 `cqu/finance,cqu/research` 后重启应用；已入库资料不需要改变 ID。空配置表示全库检索。分区控制不等于用户访问权限。

先确认机构、经费来源和人员等适用条件；不能把旧演示资料中的企业标准当作高校标准。

同层级冲突时，以生效日期较晚的版本为准；仍无法判断时返回“未知/需人工确认”，不得猜测。
