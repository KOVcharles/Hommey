# 左侧粒子 · 行程中心 Demo

参考用户提供的 `hommey-ambient-workspace.html`，保留暖灰、橙色路线和留白，将原来的底部行程中心改为左侧粒子入口与展开工作台。

## 打开

直接用浏览器打开同目录的 `left-particle-workspace.html`。HTML 内包含全部样式和脚本，无外部依赖。

也可以在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory webui_new
```

- 首页：http://127.0.0.1:8765/static/design-demos/left-particle-workspace.html
- 展开状态：http://127.0.0.1:8765/static/design-demos/left-particle-workspace.html?view=center

## 体验路径

1. 鼠标靠近左侧，粒子聚拢；点击「行程中心」，面板从左侧展开。
2. 点击「试用示例」，将一句话转换成可编辑的出发地、目的地、日期及事由。
3. 修改信息，生成并导出文本行程卡。右侧下一段旅程和最近足迹同步更新。
4. 查看已有行程，复用为新草稿；勾选准备清单，刷新后恢复。
5. 使用关闭按钮、背景或 Esc 收起；Tab 焦点约束及减少动画偏好已适配。

## 数据与功能边界

- 独立交互原型，不修改现有正式页面或业务接口。
- 自然语言填报是本地规则演示，支持部分常见城市、下周几、今天/明天/后天、明确年月日和天数；未识别字段需要手动填写，识别后需核对。
- 日期预填为下周一至周三。行程卡是本地草稿，不代表审批、订票或酒店预订；公司政策与实时交通均未连接。
- 示例行程有标记。草稿、最多 30 条历史、清单和偏好保存在 `hommey.left-particle-workspace.v1`；HTTP 和直接打开文件的浏览器存储可能不同。
- 粒子在鼠标远离、展开动画结束或页面隐藏后停止逐帧绘制。
