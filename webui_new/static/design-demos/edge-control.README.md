## 粒子

粒子沿全高右边缘分布。横向位移为：

`82 × proximity × lane × exp(-0.5 × ((y - cursorY) / 82)²)`

鼠标越靠右，波峰越向页面内侧展开；纵向均值跟随鼠标位置，远离波峰的粒子保持贴边。使用平滑插值和很小的漂移，不绕圈、不四散。静止远离时停止动画帧；页面隐藏时暂停；减少动画模式即时响应而不持续漂移。

## 主控

410px 贴边白面板，细边线，无大圆角、彩色背景、票签、装饰性英文和背景模糊。包含快速差旅、最近行程、制度入口、清单和偏好。支持 Escape、遮罩关闭、焦点约束和恢复。

本页只做界面预览；业务服务未接入。示例数据有标记，表单草稿、常用出发地和清单只写入 `hommey.edge-control.demo.v1` 本地存储。原版聊天、附件等入口保留外观并提示演示边界。

验证：浏览器检查桌面与 390px 窄屏布局、鼠标距离驱动的钟形波峰、表单保存与继续编辑；无横向溢出，未发现浏览器错误日志；JavaScript 语法检查通过。
