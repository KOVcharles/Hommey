# 从容出发 · 侧边主控概念

独立交互 demo，不依赖登录或后端接口。使用现有 Hommey 品牌、字体和本地旅行照片。

## 预览

在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory webui_new
```

打开 http://127.0.0.1:8765/static/design-demos/quiet-departure.html 。
现有服务运行时，也可直接访问 `/static/design-demos/quiet-departure.html`。

## 交互

- 距离右边缘 300px 内渐进显示粒子；越靠近，粒子和入口反馈越明显。点击入口展开主控。
- 快速差旅分为路线与日期、差旅需求、确认三步，支持校验、返回编辑和中途退出续填。
- 保存后的行程进入最近差旅，支持浏览、编辑和复制摘要；示例行程可复用。
- 出发清单、常用出发地和偏好存储在当前浏览器。
- Escape、遮罩和关闭按钮均可收起面板；提供焦点约束、移动端布局和减少动画适配。
- 粒子在鼠标远离和页面不可见时停止绘制，不影响页面交互。

## 数据边界

示例行程有明确标记。草稿、偏好和清单只写入 `hommey.quiet-departure.v1` 本地存储，不调用正式业务接口。自然语言入口保留原文为备注，仅辅助识别部分城市，日期由用户确认。制度入口展示待核对项目，不提供未经检索的企业制度。正式接入时需复用现有鉴权、地点选择和 quick_trip_form 提交逻辑。

## 验证

已在浏览器走通新建、保存、刷新后查看，以及清单勾选、Escape 关闭；检查桌面和 390px 手机布局。JavaScript 语法检查通过，浏览器检查无错误日志。
